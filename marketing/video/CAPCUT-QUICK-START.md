## 5-minute workflow

```
Import video → Import SRT (subtitles) → Record voice → Add quiet music → Export
```

### Step 1 — Import
- Open CapCut → **New project**
- **Add** → select `accredready-promo-1080p.mp4`

### Step 2 — Subtitles as guide
- **Text** → **Auto captions** → skip if using SRT
- OR: **Text** → **Import** → `accredready-promo.srt`
- Subtitles show when to speak (hide before final export if you don't want text on video)

### Step 3 — Record voice
- **Audio** → **Record** → mic icon
- Press record, play video from start, read along with subtitles
- Re-record any section: split clip, delete bad audio, record again

**Tip:** Read `VOICEOVER-SCRIPT.md` on a second phone as teleprompter.

### Step 4 — Background music (optional)
- **Audio** → **Sounds** → search "corporate" or "minimal"
- Set music volume to **15%** (voice must stay clear)

### Step 5 — Export
- **Export** → 1080p → 30fps
- Save as `accredready-promo-with-voice.mp4`
