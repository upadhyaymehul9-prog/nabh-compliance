New NABH quality manager — where to start in the first 90 days

A practical operating plan for hospital quality managers and NABH coordinators who just inherited the accreditation file — or the empty folder that should have been the file.

MU Dr. Mehul Upadhyay · Healthcare Operations Leader · Published: August 2026

In your first 90 days as a NABH quality manager, your job is not to finish accreditation — it is to install the operating system: confirm the programme (HCO Full, SHCO Full, Entry Level Certification, or ECO), complete a baseline gap analysis, form or revive mandatory committees, start indicator tracking on day one, audit statutory FMS documents, and schedule the first internal audit cycle. Official minimums to note early: Entry Level requires the hospital to be functional ≥6 months and to have NABH Standards for ≥3 months before application; SHCO Full requires ≥6 months operational data, ≥30% average occupancy over the last 6 months, and standards implemented ≥3 months. Source: nabh.co programme pages.

Do not do this first: open Word and start rewriting every SOP. Without a programme decision, a gap score, and KPI clocks running, SOP writing becomes activity theatre.

Days 1–14 — lock the mission and the baseline

  1. 1

    Confirm the NABH programme in writing

    Get leadership to name the target: HCO Full, SHCO Full (≤50 sanctioned beds), Entry Level Certification (2nd Edition; covers ≤50 and 51+), or ECO. NABH FAQs: >50 beds typically Hospital Accreditation; ≤50 beds typically SHCO or Entry Level. Use the HCO vs SHCO guide if ownership is fuzzy.

  2. 2

    Name a steering owner

    You coordinate; a Medical Director / Administrator must own blockers (budget, manpower, statutory renewals). Without that, CAPAs die in email.

  3. 3

    Inventory what already exists

    Collect SOPs, organogram, committee orders, old audit reports, training folders, and any prior NABH attempt. Mark each as current, expired, or missing.

  4. 4

    Run a ruthless baseline gap analysis

    Score objective elements as compliant / partial / non-compliant. Prioritise CORE patient-safety items first. Method: gap analysis guide.

Days 15–45 — start the clocks that cannot be rushed

These workstreams run in parallel. If you sequence them, you will lose months later.

Workstream Why it starts now First output
KPI tracking 3-month data minimum at assessment Indicator list + owners + collection started
Committees Minutes need history, not one emergency meeting Orders issued + calendar for 90 days
FMS / statutory Government renewals have long lead times Fire NOC, BMW, AERB, lift, licence status sheet
Training plan Staff interviews fail on practice, not folders Topic calendar for clinical + support staff

KPI launch — day 15, not day 60

Pick the mandatory indicators for your programme, assign a data owner per indicator, and start collection immediately. Assessors want trends and corrective action, not a pristine register created the week before assessment. Detail: NABH KPI tracking guide. Source requirement context: NABH HCO 6th Edition (2024), nabh.co.

Committees — form, then meet

Issue formal orders, define membership and quorum, and hold the first meetings. Empty letterheads do not survive assessment. For committee composition reference, see the NABH committee list.

Days 46–90 — create the quality rhythm

  1. 1

    Write SOPs only for scored gaps

    Prioritise CORE and high-risk chapters (IPC, medication, identification, consent, emergency). Version-control every document. Implement before you laminate.

  2. 2

    Schedule internal audit cycle 1

    Audit against the real gap list. Raise CAPAs with owners and dates. You will need a second cycle later — the first 90 days is when the calendar becomes real. Checklist: internal audit checklist.

  3. 3

    Install a weekly quality huddle

    30–45 minutes: open CAPAs, KPI red flags, statutory renewals due, training completion. Same agenda every week. Minutes short. Decisions named.

  4. 4

    Publish a realistic timeline to leadership

    Use your baseline score to set a date range, not a slogan. Reference the accreditation timeline guide. Include fee planning from the cost page.

90-day definition of done

✓

Programme + ownership documented (target edition named).

✓

Baseline gap analysis complete with CORE items flagged.

✓

KPI collection running for ≥30–45 days (clock started).

✓

Committees ordered, calendarised, and meeting.

✓

Statutory FMS sheet with expiry dates and owners.

✓

Internal audit cycle 1 scheduled or underway with CAPA format agreed.

✓

Leadership timeline with phases through assessment — not “ASAP.”

Tools vs consultants in month one

Consultants help with interpretation, training design, and mock assessment. They do not replace daily evidence tracking. Software helps you keep OE scores, CAPAs, committees, and KPIs in one place instead of WhatsApp folders. Decide the split early using consultant vs software and, if Excel is the current system, software vs Excel.

Common first-90-day failures

  • ×SOP factory mode — hundreds of documents, zero implementation checks.
  • ×Late KPI start — creates a hard 3-month delay at the end.
  • ×Committee letters without meetings — assessors read minutes, not letterheads.
  • ×Ignoring FMS statutory dates — fire NOC and BMW renewals can stall everything.
  • ×No CAPA owners — findings recirculate forever.

Frequently asked questions

What should a new NABH quality manager do in the first week?

Confirm the programme, get leadership ownership in writing, inventory existing documents, and start the baseline gap list. Do not begin mass SOP rewriting first. Source programme list: nabh.co.

When should KPI tracking start in NABH preparation?

At the start of structured preparation. NABH requires a minimum of 3 months of quality indicator data at assessment. Source: NABH HCO 6th Edition (2024), nabh.co.

How many internal audit cycles should be done before NABH assessment?

At least two complete cycles with CAPA closure. Put cycle 1 on the calendar inside the first 90 days.

Should a new quality manager hire a NABH consultant immediately?

Not before you own the baseline. Use paid help for interpretation and mock assessment after the hospital can track evidence day to day.

What is a realistic goal for the first 90 days of NABH preparation?

Programme confirmed, gap analysis done, committees meeting, KPIs running, statutory sheet live, first audit scheduled, and a phase timeline shared with leadership.

Sources: Programme definitions and assessment data expectations from NABH documentation at nabh.co and NABH HCO 6th Edition (2024). The 90-day sequencing is a practitioner operating plan for hospital quality teams, not a NABH-published schedule.
